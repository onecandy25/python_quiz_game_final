# Python 퀴즈 게임 🎯

코디세이 경남 미션 2를 위한 Python 콘솔 퀴즈 게임입니다.
Python 기초 개념을 묻는 객관식 퀴즈를 풀고,
직접 문제를 추가할 수 있습니다.
최고 점수와 추가한 문제는 파일에 저장되어 다음 실행 때도 유지됩니다.

## ✨ 주요 기능

- **퀴즈 풀기**: 등록된 문제를 순서대로 풀고 점수를 확인
- **최고 점수 저장**: 신기록 달성 시 축하 메시지 표시
- **문제 추가**: 사용자가 직접 문제·보기·정답·해설 등록
- **문제 개수 확인**: 현재 등록된 문제 수 출력
- **자동 저장/불러오기**: `state.json`에 최고 점수와 문제를 저장

## 📂 파일 구성

| 파일 | 설명 |
|------|------|
| `main.py` | 게임 실행 코드 |
| `state.json` | 최고 점수·문제 저장 파일 (자동 생성) |

## 🚀 실행 방법

```bash
python main.py
```

## 🎮 메뉴 설명

| 번호 | 기능 |
|------|------|
| 1 | 퀴즈 시작 |
| 2 | 문제 개수 확인 |
| 3 | 문제 추가 |
| 4 | 종료 |

## 📝 기본 문제 (Python 기초 5문제)
1. 문자열을 나타내는 기호
2. 주석을 작성하는 기호
3. 리스트를 만드는 괄호
4. 반복문 키워드
5. 함수를 만드는 키워드

## 🧩 코드 구조
1. Quiz 클래스: 문제 하나(질문·보기·정답·해설)를 담당
2. show_question(), check_answer(), to_dict(), from_dict()
3. QuizGame 클래스: 게임 전체 진행을 담당
4. start_quiz(), add_quiz(), save_state(), load_state(), run()

## 🛡️ 예외 처리
1. 빈 입력 / 숫자가 아닌 입력 처리
2. Ctrl+C, Ctrl+D(입력 중단) 안전 처리
3. 저장 파일 손상 시 기본 문제로 복구
